# 数学错题本

## 题目：

设 $a_1, a_2, \cdots, a_n$ 是 $n$ 个正数，则称

$\frac{a_1 + a_2 + \cdots + a_n}{n}$ 是它们的算术平均值；

$\sqrt[n]{a_1 a_2 \cdots a_n}$ 是它们的几何平均值；

$n \left/ \left( \frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n} \right) \right.$ 是它们的调和平均值。

这三个平均值之间成立如下关系：

对任意 $n$ 个正数 $a_1, a_2, \cdots, a_n$，有

$\frac{a_1 + a_2 + \cdots + a_n}{n} \geqslant \sqrt[n]{a_1 a_2 \cdots a_n} \geqslant n \left/ \left( \frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n} \right) \right.$,

等号当且仅当 $a_1, a_2, \cdots, a_n$ 全部相等时成立。
